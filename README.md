# ドパドリル

[日本語] · [Español](README.es.md)

算数を1問解くたびに、演出と音楽がどんどん盛り上がっていく計算ドリルです。ブラウザだけで動きます。

マスコットの「ドパキチ」が入力した数字を運び、正解すると祝ってくれます。問題を進めるほど画面と音が増えていき、最後はお祭りのような状態になります。まちがえても勢いは落ちず、ゲームオーバーもありません。

画面はスペイン語と英語で表示します（[スペイン語のREADME](README.es.md)）。はじめは端末の言語（スペイン語ならスペイン語、それ以外は英語）で開き、「せってい」でいつでも切り替えられます。原文の日本語で確認したいときだけ `?lang=ja` を付けて開いてください（開発・保守用）。

ゲーム本体は `app/` に1つだけあり、そこから3つの形で出荷します。

| フォルダ | 内容 |
| --- | --- |
| `app/` | ゲーム本体（HTML/CSS/JS、依存なし）。Web版であり唯一の原本 |
| `ios/` | ゲームを内包したXcodeプロジェクト（Capacitor） |
| `android/` | ゲームを内包したAndroidプロジェクト（Capacitor） |

モバイル版は同じWebアプリをそのまま包むので、機能は100%そのままです（Web Audioの合成音、WebGLの背景、粒子、SVGのキャラクター、localStorageの保存）。手順は [MOBILE.md](MOBILE.md)（スペイン語）にまとめています。

```bash
npm install
npm run sync      # app/ を ios/ と android/ にコピー
npm run apk       # 確認用APK
npm run ios:build # iOSがビルドできるか確認
```

## 特徴

- 小学1〜6年の計算58スキル（学習指導要領に基づく）。足し算・ひき算・かけ算・わり算、筆算の途中入力、小数、分数、割合など
- 「じぶんレベル」モード：実力チェックの結果から始め、習熟に合わせて次のスキルを解放します
- 学年別モード、練習、復習、スキルツリー画面
- 全問正解で100点。初回正解率が80%以上なら、制限時間付きのエクストラで100点を超える得点を狙えます
- 音楽と効果音はすべてWeb Audio APIで合成しています（音声ファイルは使っていません）
- スマートフォンの縦画面とPCに対応。PCでは数字キーとBackspaceで入力できます
- 設定で動きの強さを調整できます。ミュートもあります
- 記録はすべて端末内（localStorage）に保存し、外部には送信しません

## 遊び方（ローカル）

ビルドは不要です。`app/` を静的に配信するだけで動きます。

```bash
python3 -m http.server 8000 -d app
```

ブラウザで `http://localhost:8000/` を開いてください。ES Modulesを使っているため、`file://` で直接開くと動きません。

## テスト

Node.js 20以上で実行します。

```bash
node --test tests/*.test.mjs
```

翻訳の抜け（スペイン語・英語の対応と、画面に残った日本語）は次で確認できます。

```bash
node tools/check_i18n.mjs
```

## 構成

| パス | 内容 |
| --- | --- |
| `app/` | ゲーム本体（依存ライブラリなしのES Modules） |
| `app/js/i18n.js` | 日本語・スペイン語の文言と言語の切り替え（英語は `app/js/i18n.en.js`） |
| `docs/SPEC.md` | 仕様書 |
| `docs/curriculum.md` | 学年別カリキュラムとスキルツリーの設計 |
| `docs/dopakichi.svg` | ドパキチの造形の原典 |
| `tests/` | 単体テスト |
| `tools/build_fonts.sh` | フォントのサブセット再生成（画面の文言を追加したときに実行） |
| `tools/check_i18n.mjs` | 翻訳の抜けと、スペイン語・英語に残った日本語のチェック |
| `tools/dom_smoke.mjs` | 画面を実際に動かして言語切り替えを確かめる確認用（jsdomが必要） |
